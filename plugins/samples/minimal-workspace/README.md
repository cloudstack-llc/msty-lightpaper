# Minimal Workspace

A serious theme/plugin sample inspired by Obsidian Minimal's architecture. It proves that LightPaper themes can now ship CSS assets, expose per-theme settings, declare layout modes, style semantic shell slots, use frontmatter `cssClasses`, and mount companion UI panels.

Try the `Minimal: Activate Theme` command, then switch layouts with `Minimal: Focus Layout`, `Minimal: Wide Layout`, or `Minimal: Cards Layout`. Use `Minimal: Insert Style Guide Note` to create a note that exercises frontmatter `cssClasses`, cards, list cards, tables, image grids, and alternate checkboxes.
